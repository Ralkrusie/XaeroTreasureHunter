# Xaero TreasureHunter

Xaero 小地图 / 世界地图的附属 mod：客户端扫描附近**已加载区块**中的目标方块，并把它们以**临时路径点**的形式显示在地图上。

灵感来自原版调试饼图技巧（Pie-Ray，kemytz 发现）：原版要盯着饼图条目、靠走位扫出刷怪笼 / 箱子 / 钟的位置；Xaero TreasureHunter 直接把位置标在地图上。

## 目标方块（0.11.0）

- 刷怪笼（地牢、地狱堡垒、要塞传送门室）
- 箱子 / 陷阱箱 / 木桶（地牢、村庄、埋藏宝藏、船……）
- 钟（村庄）

## 使用

- 默认按键：
  - `G`：开关扫描
  - `H`：清空所有标记（并尝试移除路径点），同时关闭扫描（按 `G` 重新开启）
  - `J`：打开扫描设置菜单（带分类图标与 ✔/✘ 状态标识；勾选刷怪笼 / 箱子 / 木桶 / 钟，以及发现提示、仅单人、来源智能识别、邻近标记合并；改动立即保存）
- 来源智能识别（可在设置里关）：
  - 箱子 / 木桶会按周围特征方块分类标注：`[地牢箱]`、`[村庄箱]`、`[猪灵箱]`、`[试炼箱]` 等
  - `[宝藏箱]`：区块局部 X/Z 均为 9 + 单个普通箱子 + 被遮盖（上必须、侧 ≥3 面），置信度很高
  - `[地牢箱]` 要求「刷怪笼 + 苔石」；`[矿井箱]` 为 刷怪笼+蛛网 / 铁轨 / 蛛网+木板
  - `[府邸箱]` 要求深色森林群系；`[前哨站箱]` 与府邸同系深色橡木，但只在非深色森林群系、且附近有圆石 / 苔石 / 羊毛证据时判定（与沉船区分：沉船只有木头没有圆石）
  - `[丛林神庙箱]`：苔石 +（绊线陷阱 / 雕纹石砖）+ 丛林或竹林群系
  - `[海底废墟箱]`：水下 + 石砖族（冷海）或砂岩族（暖海），海平面以下
  - `[沙漠神殿箱]`：砂岩 + 陶瓦/TNT 且非水下（避免误判含砂岩的水下废墟）
  - `[传送门遗迹箱]`：黑曜石 + 哭泣的黑曜石（主世界也可用 黑曜石 + 下界岩 判定）
  - `[沉船箱]`：水下 + 木质结构（含深色橡木为主的混合木船体）
  - `[堡垒箱]` / `[猪灵箱]`：优先看箱子**正下方**——下界砖 = 堡垒、黑石族（含镶金黑石）= 猪灵；周边方块证据作兜底（下界天然黑石斑块常见，故堡垒判定优先）
  - 高度辅助：试炼箱、远古城市箱只在地下（y < 20）判定；府邸箱、前哨站箱要求纯地表高度（y > 50）；沙漠神殿箱（深坑宝库）、丛林神庙箱（宝库）、雪屋箱（地下室）用保守下限 y > 35——用于排除玩家自建的地表/地下结构
  - 路径点按分类着色，简称用结构代表汉字（宝/试/矿/牢/猪/堡/末/古/村/沙/林/要/哨/邸/船/雪/海/门），刷怪笼、钟用字母（S / B）
  - 刷怪笼显示生物种类，如 `[蜘蛛笼]`、`[烈焰人笼]`（客户端同步的真实数据，非推断）
  - 双联箱只登记一个路径点
- 箱子类型过滤（设置菜单 → 「箱子类型过滤…」）：逐类开关是否扫描；关闭的类别不再登记（已标记的会移除），重新打开后下一次重扫会重新发现
- 开箱后自动删除：打开并关闭某个箱子/木桶后，对应路径点自动移除，且该容器不再被重扫加回（记忆在离开世界时清空；箱子用开合动画检测，木桶用距离近似）
- 邻近标记合并（可在设置里关）：半径 5 格内已有相同标记（同类型 + 同分类）时不再重复标记；关闭后每个匹配都会标记
- 路径点生命周期：自建路径点会记录所属维度的路径点集，维度切换 / 传送 / 清空（H）都能可靠清理，不会留下无法删除的残留
- 扫描策略：只扫"新加载 / 尚未扫过"的区块（进入视距即扫、不重复扫已完成的区块），范围覆盖整个客户端已加载区域（视距即上限）；每 2 秒兜底检查一次漏网区块；容器分类前会确认证据区域已加载完整，未完成时自动推迟重试
- 清空标记（`H`）会重置区块扫描记录（区域内目标会重新发现），但"已搜刮"记忆保留
- 配置：`config/treasurehunter.json`（旧 trackit.json 会自动迁移；兜底扫描间隔、目标开关、通知、单人限定等）
- 默认仅在**单人世界**启用（多人服务器上这类扫描通常被视为透视/作弊，请自行判断）。

## 构建

需要 JDK 25（MC 26.2 要求 Java 25）。

```
./gradlew build
```

> 作者开发机备注（不影响克隆后的构建）：本机处于 TLS 检查代理之后，Java 直连下载会 PKIX 失败；相关规避（Gradle 发行版缓存、用户级 `~/.gradle/gradle.properties`）均保留在本机，不在仓库中。

产物在 `build/libs/xaero-treasurehunter-0.11.0.jar`。

## 本地测试（runClient）

`run/mods/` 里已经放好 26.2 版的 Xaero 小地图 / 世界地图 jar：

```
./gradlew runClient
```

进单人世界后：
- 按 `G` 开关扫描；
- 发现的刷怪笼 / 箱子 / 木桶 / 钟会以小地图（及世界地图）路径点出现，颜色与简称按分类区分（见上）；
- 按 `H` 清空所有标记（同时移除路径点）；
- 按 `J` 打开扫描设置菜单。

## 依赖

- Fabric Loader ≥ 0.19.5（26.2）
- Fabric API
- 可选：Xaero's Minimap（推荐 26.5.1+，26.2 版）。没有 Xaero 时 mod 静默降级，只保留扫描日志 / 通知。本模组不包含任何 Xaero 代码，仅通过反射调用其公开内部 API（不保证跨版本兼容，API 变化时自动禁用集成并给出一次警告）。

## 提醒
